## Current-view limit found during the proof

The typed holder proof first served requests with `drive_workspace`. A newly admitted holder
still needed its initial self-update. The driver advanced its membership epoch before it
served an older-epoch current query. The query returned `holder has no current view`.

The binding proof now serves this fixed-epoch query with `poll_control`, as the existing JSON
holder tests do. This proves the typed mapping at a fixed epoch. It does not prove catalog
continuity across a normal membership epoch change. H1 re-publication handles a losing branch;
it does not add current-value re-publication for every normal epoch transition. Root and H1
have this case. It remains a general retained-content integration gap.
