### SFrame decision

The [SFrame 2.0 changelog](https://raw.githubusercontent.com/TobTheRock/sframe-rs/v2.0.0/CHANGELOG.md)
changes the frame counter API to report failure. Core now uses `try_with_meta_data` and
maps counter failure to its existing counter-exhausted result. The existing object test
also exercises the last valid u64 counter and the next rejected send.

The [2.0 manifest](https://raw.githubusercontent.com/TobTheRock/sframe-rs/v2.0.0/Cargo.toml)
requires Rust 1.85 and offers ring as its default backend. H6 selects ring explicitly.
The optional RustCrypto backend would select AES-GCM 0.11; it stays off. Core AES-GCM
stays at 0.10 to match OpenMLS 0.6 and Iroh/Noq. Both manifests state this reason.
