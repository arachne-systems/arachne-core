# `arachne-routing`

Provides workspace-scoped topic validation, endpoint permissions, subscription
interest, and recipient selection. It does not authenticate identities or
verify policy changes; callers must install policy derived from trusted,
accepted workspace state.

See the [architecture][architecture] and [security model][security].
