# `arachne-runtime`

Composes the Arachne Core crates and exposes the typed, synchronous Rust
`Client` API for workspace lifecycle, membership, routing, publication, and
recovery operations.

See the [integration guide][integration] for the persistence contract and a
runnable example. APIs and saved formats are pre-release.

[integration]: https://github.com/arachne-systems/arachne-core/blob/main/docs/integration.md
