# `arachne-node`

Provides Iroh-based authenticated peer connectivity, address discovery, and
message transport. It does not own workspace membership, application identity,
or domain-specific payload parsing.

See the [architecture][architecture] and [security model][security].
Connectivity depends on the selected network profile and deployment
environment.

[security]: https://github.com/arachne-systems/arachne-core/blob/main/docs/security.md
