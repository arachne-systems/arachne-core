# `arachne-security`

Implements MLS workspace state, invitations, admission and membership
transitions, and protected application messages. It has no ATAK, Android,
transport, or application-payload-format dependency.

See the [security model][security] and [architecture][architecture]. APIs and
persisted formats are pre-release.

[security]: https://github.com/arachne-systems/arachne-core/blob/main/docs/security.md
[architecture]: https://github.com/arachne-systems/arachne-core/blob/main/docs/architecture.md
